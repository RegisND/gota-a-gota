# Gota a Gota

App web de acompanhamento da hidratação diária, desenvolvido para o projeto de extensão
"Meio Ambiente e Saúde" do curso de Análise e Desenvolvimento de Sistemas (Cruzeiro do Sul Virtual).

- Meta diária: 35 ml por kg de peso (+500 ml para atividade física ou calor).
- Registro rápido de copos, histórico de 7 dias e garrafinhas plásticas evitadas.
- Dados salvos apenas no aparelho do usuário (localStorage), sem login e sem servidor.
- Funciona offline e pode ser instalado na tela inicial (PWA).

Aviso: a meta é uma referência geral para adultos saudáveis e não substitui orientação médica.
